# ワントップ → 記事たたき台 自動化セット

## 全体の流れ

```
①教材を自動保存 → ②Claude Codeで記事たたき台を自動生成
```

---

## ① 教材を自動保存する（ワントップ自動保存.command）

サイトの内容をObsidianに自動でまとめて保存します。

1. `ワントップ自動保存.command` をダウンロード
2. ターミナルで実行権限をつける（初回のみ）
   ```
   chmod +x ~/Downloads/ワントップ自動保存.command
   ```
3. ダブルクリックで起動
4. ブラウザが開く → ワントップにログイン
5. 目次ページを表示したら、ターミナルに戻って **Enter**
6. 自動で全ページを保存

保存先: `ブログ/ブログ教材「ワントップ」`
※ 第1章など保存済みのページは自動でスキップされます。

---

## ② 記事のたたき台を自動生成する（記事たたき台コマンド）

Claude Codeに、教材を読ませて記事のたたき台まで作らせます。

### 準備（初回のみ）

`obsidianに置くファイル` の中の `.claude` フォルダを、
あなたのObsidianフォルダの直下にコピーします：

```
/Users/kotomitooyama/kot_memo_obsidian/.claude/commands/記事たたき台.md
```

### 使い方

1. ターミナルでObsidianフォルダに移動して claude を起動
   ```
   cd /Users/kotomitooyama/kot_memo_obsidian
   claude
   ```
2. 次のコマンドを入力するだけ
   ```
   /記事たたき台
   ```
3. AIが教材を読み、テーマ（穴場キーワード）を5つ提案します
4. 作りたい番号を伝えると、教材メソッドに沿った記事のたたき台を生成
5. `ブログ/記事たたき台` フォルダに自動保存されます

---
