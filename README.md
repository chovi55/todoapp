# AIポスト工房

X / Threads の投稿を、テーマ1行から作るためのWebツール。
12個のツールが1ページに入っていて、生成された文章はそのままコピーして投稿できます。

`index.html` 1ファイルで完結しています。ビルド不要、依存パッケージなし。

## 収録ツール

### ポスト作成
| ツール | 入力 | 出力 |
| --- | --- | --- |
| オールマイティ | テーマ1行 | 短文 / 王道 / リプ誘導の3案 |
| 〇×型 | テーマ | 本文に✕、リプに〇を1対1で対応させた対比ポスト |
| ランキング | お題・順位数 | ランキング本文＋理由のリプ |
| 共感ストーリー | 題材・体験メモ | 本文＋連投リプの物語（リプ2〜5） |
| メダル型 | テーマ | 🥇🥈🥉の3段＋選定理由のリプ |
| 商品紹介・PR | 商品画像 / 商品名 | 訴求点を絞ったPR文3案（短文・王道・リプ誘導） |

### 図解メーカー
| ツール | 入力 | 出力 |
| --- | --- | --- |
| 図解（やわらか） | テーマ・項目数 | パステル配色の図解画像＋添えるポスト案 |
| 図解（手書き風） | テーマ・項目数 | ノート風の図解画像＋添えるポスト案 |

図解は AI が中身（タイトル・項目・注意書き）を書き、**レイアウトはブラウザ側の組版エンジンが描画**します。
文字幅を実測して折り返すので、はみ出しや文字被りが起きません。PNG / SVG で保存できます。

### アカウント設計・運用サポート
| ツール | 入力 | 出力 |
| --- | --- | --- |
| プロフィール最適化 | 現在のプロフ・実績 | 5軸の採点＋直し方＋シンプル版/通常版の2案（160字以内） |
| 投稿ネタ出し | ジャンル | 伸びやすいネタ10個（型・書き出し案つき、そのまま各ツールへ送れる） |
| 辛口診断 | 投稿前のポスト案 | 5軸の採点＋具体的な直し方＋改善案3つ |
| 伴走コーチ | 投稿のスクショ・数字 | 数字を根拠にした分析＋明日やること＋次のポスト案2つ |

## 全ツール共通の仕組み

- **アカウント設定**（発信ジャンル / 読者 / 語り口 / 一人称）を1回入れると、全ツールのプロンプトに差し込まれます。
- 生成文には **X基準の全角換算カウンタ**（全角=2ウェイト、140字=280ウェイト）が付きます。超過は赤字。
- リプ（連投）はスレッド線でつないで表示。本文だけ・リプだけ・スレッド全体、それぞれ個別にコピーできます。
- 入力内容とアカウント設定は `localStorage` に保存されるので、閉じても消えません。

## 使い方

### 1. Artifact として開く（推奨・設定不要）
claude.ai の Artifact として公開すると、ページから直接 Claude を呼べるので **APIキーもアカウント登録も不要**です。
生成は閲覧者自身の Claude 利用枠で動きます。

### 2. ローカルで開く
```
open index.html
```
ブラウザから直接開いた場合は AI を呼べないため、各ツールの **「プロンプトをコピー」** ボタンで
指示文を取り出して、ChatGPT / Claude / Gemini に貼り付けてください。出力される内容は同じです。

## カスタマイズ

プロンプトは `index.html` の中に3か所で完結しています。

- `CORE` … 全ツール共通の運用知見（伸びる原則 / 禁止事項 / 文字数の目安）。ここを直すと全ツールの文体が変わります。
- `F_POSTS` / `F_REVIEW` / `F_IDEAS` / `F_FIGURE` … 出力JSONの形式定義。
- `TOOLS` 配列 … 各ツールの `fields`（入力欄）と `prompt()`（指示文）。配列に足すだけでツールを増やせます。

図解のデザインは `THEMES`（配色）と `buildFigure()`（組版）にあります。

## 制約

- AI はWeb検索をしません。出力は学習済みの知識に基づく一般論です。**固有名詞・数字・価格・効能は必ず自分で裏取りしてから投稿してください。**
- 医療・投資・美容の断定表現、効果保証は出力しないようプロンプト側で抑えていますが、最終確認は投稿者の責任です。
- 画像入力（商品紹介・伴走コーチ）は、実行環境が画像に対応している場合のみ表示されます。
